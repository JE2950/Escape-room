# Fuga Romana — illustrated interface

Open index.html in any modern browser. No installation or server is required.

The five rooms, all 15 questions, answer choices, accepted answers, grammar hints,
feedback, attempt limits and scoring rules are preserved from the original.

This edition adds Roman environment artwork, a parchment puzzle panel, bronze
navigation styling, a five-room progress trail, responsive layouts, keyboard
access to word tokens and reduced-motion support.

Artwork was generated with the built-in image generation tool. Prompt: a cohesive
six-scene cinematic Roman environment atlas showing a city entrance, Forum
marketplace, soldiers' camp, villa courtyard, harbour and open gate; painterly
realistic stone and bronze details, midnight teal shadows and amber lamps; no
text, UI or puzzle clues. Images are stored in assets/*.webp.

assets/interface.css and assets/interface.js form the presentation layer.
The original game data and game logic remain in index.html.
